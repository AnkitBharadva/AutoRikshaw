# Auto Rickshaw 🛺

A nostalgic, vibe-driven single-page music playlist website themed around Ahmedabad auto-rickshaws.

## Features

- **Retro Tape Deck Player:** A functional and animated tape deck that simulates playing cassette tapes.
- **Nostalgic Playlist:** Curated 80s & 90s Hindi and Gujarati hits to transport you to the backseat of a CNG rickshaw.
- **Auto-Rickshaw Aesthetic:** Warm saffron, deep green, and cream colors, with subtle grain overlays and a custom hand-drawn inline SVG rickshaw that idles playfully.
- **Scroll Fare Meter:** A stylized dashboard fare meter that increases as you scroll down the page, giving a classic Ahmedabad rickshaw experience.

## Usage

This project is a completely static, pure HTML/CSS/JS experience without any framework dependencies.
Just open `index.html` in your web browser.
